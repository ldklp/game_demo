# ForestTable · 可玩原型 v2.0（d6 战斗版）

> 属性压到 15~25、新增「伤害」、所有判定只用一颗六面骰、
> 战斗改成每节拍双方各投 d6 抢行动权。
> 完整数值说明见 **`设计文档_v2.html`**（用浏览器打开，可直接打印）。

---

## 一、怎么跑

双击 `index.html` 就能玩，不用装东西、不用服务器。

打不开的话：

```bash
python -m http.server 8080     # 然后访问 http://localhost:8080
```

## 二、这一版的手感

选一个角色 → 进森林 → 走完 4 个阶段到湖畔即逃出。约 **50~70 回合**（10~14 天）。

**一回合**：事件结算 → 选一个行动（前进 / 收集 / 合成 / 休整）→ 自然消耗结算。

**一场战斗**：每个**节拍**双方各投一颗骰子抢出手权，抢到的人行动。

```
第 3 节拍 · 抢行动权
   你   5 -1 = 4        ← 连击惩罚 -1（上节拍也是你动）
   它   3 +1 = 4        → 平手，你优先
→ 你行动：攻击 / 防守 / 用道具 / 撤退
```

- 连续行动的一方，本次所有判定 **-1**（第三次起 -2），对方行动一次后清零。
- 每把武器有自己的**暴击骰面**：猎枪投出 **4** 就是双倍伤害。
- 体力见底会力竭，精神归零会崩溃——两者都有 **3 回合宽限**，来得及自救。

## 四、调数值

全在 `js/data.js` 顶部 `FT.CONFIG`，改完刷新：

```js
CHAIN_PENALTY_STEP: 1,    // 连击每次 -1
CHAIN_PENALTY_MAX:  2,    // 惩罚上限（想严格按 -1 就改成 1）
DEFEND_REDUCE: 3,         // 防守减伤
REST_HP: 2,               // 休整回多少健康（调到 3 会明显变简单）
PROGRESS_GOALS: [5,6,7,8],// 四阶段进度阈值 ← 调节奏最有效
TURN_SANITY_NIGHT: 2,     // 夜间精神消耗
```

内容表：`FT.CHARS`（4 角色）`FT.ITEMS`（含武器 `weapon:{dmg,crit,hit}`）
`FT.RECIPES`（19 个配方）`FT.ENEMIES`（含四阶段血量 `hp:[s1,s2,s3,s4]`）`FT.CARDS`（64 张）。

## 五、当前基线（`node js/_selftest.js 20`）

| 指标 | 结果 |
|---|---|
| 通关 | 18 / 20（机器人几乎不打精英，所以偏稳） |
| 平均回合 | 63.1 |
| 平均战斗长度 | 6.5 节拍（普通 4~6，精英 14~18） |
| 精英遭遇 | 2.3 次 / 局（每阶段最多一次） |
| 暴击 | 2 次 / 局（≈1/6，符合设计值） |
| 运行时错误 | 0 |

单挑（`node js/_duel.js`，各 300 次）：

| 对局 | 玩家胜率 |
|---|---|
| 猎人·猎枪 vs 阶段1 野兽 | 100% |
| 猎人·猎枪+磨刀石 vs 骨面酋长（42） | 64% |
| 猎人满配 vs 雾中行者（72） | 40% |

**设计口径**：普通遭遇是"必赢但会掉血"，精英是"要不要赌"。
带齐装备打最终精英是四成胜率，赢下来剩 2 点血。

## 六、与 v1.1 的差异（简版）

| | v1.1 | v2.0 |
|---|---|---|
| 属性 | 0~100 三项 | **15~25 四项**（+伤害） |
| 判定 | d20 + 修正 | **1d6 + 修正 vs 3~6** |
| 战斗 | 双方各打一轮 | **每节拍抢行动权 + 连击 -1** |
| 暴击 | 自然 20 | **每把武器一个骰面** |
| 敌人 | 固定血量 | **四阶段血量表**，精英 42~72 |
| 死亡 | 直接退场 | 濒死 / 崩溃都有 3 回合宽限 |
